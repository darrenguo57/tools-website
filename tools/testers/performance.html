How to Use

About This Tool

The Performance Test tool analyzes HTML documents and generates a score along with actionable optimization suggestions. It checks document size, DOM element count, image attributes, CSS and JavaScript references, render-blocking resources, and essential meta tags. The result is presented as a numeric score with color-coded recommendations that help you improve page load speed and user experience.

Input Guide

Paste your HTML source code into the input area. You can load a sample document to see how the analysis works, paste from your clipboard, or type directly. The tool parses the HTML in the browser using a DOM parser, so the code does not need to be rendered by a server. Ensure you paste the full source including the DOCTYPE, head, and body sections for the most accurate results.

Output

The output panel displays a circular score from 0 to 100, color-coded as Excellent (green), Good, Fair, Needs Improvement, or Poor (red). Below the score, a Details section lists quantitative metrics such as HTML size, element count, image count, and external resource counts. The Suggestions section provides specific, prioritized recommendations with severity icons. Each suggestion includes context and, where applicable, example code snippets.

Tips & Notes

  • A high score does not guarantee fast load times; server response and CDN usage also matter.
  • Inline styles and scripts reduce cacheability even if the score penalty is small.
  • Missing image dimensions cause cumulative layout shift, which hurts Core Web Vitals.
  • Use the sample HTML to familiarize yourself with the scoring logic before analyzing your own code.

Common Use Cases

Frontend developers audit landing pages before launch. SEO specialists check that viewport and description meta tags are present. Designers verify that images include alt text and explicit dimensions. DevOps engineers review HTML templates generated by server-side frameworks. Educators teach web performance basics by showing students how individual changes affect the overall score.
