URL Encoder/Decoder

Encode and decode URL components

URL encoding (percent-encoding) converts unsafe ASCII characters into a format safe for transmission in URLs. Essential for handling query strings, form data, and non-ASCII characters like Chinese, Arabic, or emoji in web addresses. Supports both encodeURI and encodeURIComponent modes.

How to Use

About This Tool

The URL Encoder/Decoder handles percent-encoding and decoding of Uniform Resource Locators. URLs can only be sent over the Internet using the ASCII character set, so non-ASCII characters, spaces, and reserved symbols must be converted into a valid format. This tool automatically handles RFC 3986 compliant encoding while preserving URL structure and query parameter separators.

Input Guide

Paste any URL, query string, or form data that needs encoding. For decoding, paste a percent-encoded string such as Hello%20World%21. The tool intelligently detects whether to encode or decode based on your selected mode. You can also process individual query parameters or entire URLs with multiple parameters.

Output

Encoded output replaces unsafe characters with percent signs followed by two hexadecimal digits (e.g., space becomes %20). Decoded output restores the original characters. The tool preserves structural characters like ?, &, and = in URL mode, or fully encodes everything in raw mode.

Tips & Notes

  • Double-encoding is a common mistake — verify that your input is not already encoded before processing.
  • Use "Encode URI Component" mode for individual query parameter values to avoid breaking URL structure.
  • Certain characters like #, &, and = have special meaning in URLs and should always be encoded in query values.
  • The plus sign (+) represents a space in application/x-www-form-urlencoded data but not in standard percent-encoding.

Common Use Cases

This tool is essential when constructing API requests with dynamic query parameters, handling user-generated content in URLs, debugging broken links caused by special characters, processing OAuth callback URLs, and preparing data for HTML form submissions. Frontend and backend developers alike rely on URL encoding for safe data transmission.
