How to Use

About This Tool

The Relation Graph tool visualizes networks of nodes and edges using a force-directed layout. It is ideal for modeling social networks, system dependencies, organizational hierarchies, and knowledge graphs. Nodes are colored automatically, and edges include directional arrows. The layout engine minimizes edge crossings and clusters related nodes together for intuitive exploration.

Input Guide

Build your graph using the node table. Each row defines a node name and a comma-separated list of connected nodes. The tool infers edges from these connections. You can add nodes dynamically and choose between force-directed, circular, and grid layouts. Node names should be unique; duplicate names are treated as the same node. The force-directed layout works best for highly connected graphs.

Output

The output is an interactive canvas graph. Nodes are represented as circles with labels. Edges are lines with arrowheads showing direction. In force-directed mode, you can drag nodes to rearrange the layout manually. The graph updates in real time as you edit the data table. Download the rendered image as a PNG for documentation or presentations.

Tips & Notes

  • Limit graphs to under 100 nodes for smooth interaction.
  • Use the circular layout when you want a deterministic, symmetrical shape.
  • Disconnected nodes still appear but may drift to the edges.
  • Node colors cycle through a fixed palette and repeat if there are many nodes.

Common Use Cases

Software architects map microservice dependencies. Security teams model network topology and trust relationships. HR departments visualize reporting structures. Researchers study citation networks and collaboration graphs. Game designers plot faction alliances and conflict webs.
