How to Use

About This Tool

The Base64 Crypto tool provides Base64 encoding and decoding with optional AES encryption. Base64 is a binary-to-text encoding scheme that represents data as ASCII characters, making it safe to embed in JSON, XML, URLs, and email bodies. When combined with AES encryption, you can transform sensitive plaintext into an encrypted Base64 string that can only be decrypted with the correct password.

Input Guide

Enter the text you want to encode or the Base64 string you want to decode. For encryption, check the Encrypt option and enter a strong passphrase. The tool uses AES-256-GCM by default, which provides both confidentiality and authentication. If you are decoding, ensure the input is valid Base64; the tool will warn you about invalid characters or incorrect padding.

Output

For encoding, the output is a Base64 string. For decoding, the output is the original text or binary data. When encryption is enabled, the output is a Base64-encoded ciphertext that includes the nonce and authentication tag. The encrypted output can be safely shared over public channels, but the passphrase must be kept secret.

Tips & Notes

  • Base64 is not encryption by itself; it only obscures data. Use AES encryption for secrets.
  • The encoded output is roughly 33% larger than the original binary data.
  • Never hard-code encryption passphrases in client-side JavaScript for production.
  • Store the nonce alongside the ciphertext; it is required for decryption.

Common Use Cases

Developers embed small images directly into CSS or HTML as Base64 data URIs. API clients encode binary payloads in JSON fields. Mobile apps encrypt local configuration values before storing them. System administrators encode certificates and keys for safe transport via chat or email.
