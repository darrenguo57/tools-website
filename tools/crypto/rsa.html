How to Use

About This Tool

The RSA tool demonstrates asymmetric cryptography by generating public-private key pairs, encrypting messages with the public key, and decrypting with the private key. RSA is widely used for secure key exchange, digital signatures, and certificate-based authentication. This educational tool uses standard RSA-OAEP padding and supports key sizes from 512 to 4096 bits.

Input Guide

Click Generate Keys to create a new key pair. The public key can be shared openly, while the private key must be kept secret. To encrypt, enter plaintext and select the recipient's public key. To decrypt, paste the ciphertext and provide the matching private key. The tool accepts PEM-formatted keys. Key generation may take a few seconds for 2048-bit and larger keys.

Output

Key generation produces a PEM-encoded public key and private key. Encryption output is a Base64-encoded ciphertext. Decryption recovers the original plaintext. If the keys do not match or the ciphertext is corrupted, the tool returns an error. The maximum plaintext length depends on the key size and padding scheme; longer messages should use hybrid encryption.

Tips & Notes

  • Key sizes below 2048 bits are considered weak and should not be used in production.
  • Never share your private key; treat it like a password.
  • RSA encryption is slower than AES; encrypt large files with AES and protect the AES key with RSA.
  • The tool runs locally; generated keys are not stored or transmitted.

Common Use Cases

Students learn how public-key cryptography works without installing OpenSSL. Developers prototype secure messaging features. Security engineers verify key formats before importing them into production systems. Penetration testers generate test certificates for lab environments.
