How to Use

About This Tool

The AES Encryption tool performs symmetric encryption and decryption using the Advanced Encryption Standard. It supports AES-128, AES-192, and AES-256 in CBC and GCM modes. AES is the global standard for encrypting sensitive data at rest and in transit. This tool lets you encrypt plaintext with a password and later decrypt it using the same password, all within your browser.

Input Guide

Enter your plaintext in the input area and provide a passphrase. Choose the key size and mode. AES-256-GCM is recommended for the strongest security. For CBC mode, a random IV is generated automatically and prepended to the ciphertext. For GCM mode, the nonce and authentication tag are included in the output. When decrypting, paste the complete ciphertext string and enter the exact passphrase used during encryption.

Output

The encryption output is a Base64-encoded string containing the ciphertext plus any required metadata such as IV, nonce, or tag. The decryption output is the recovered plaintext. If the passphrase is incorrect or the ciphertext has been tampered with, the tool displays a decryption error. No raw binary is exposed; everything is handled as safe text.

Tips & Notes

  • Use a long, random passphrase for strong security; avoid dictionary words.
  • GCM mode is preferred over CBC because it provides built-in authentication.
  • Never reuse an IV or nonce with the same key.
  • This tool is for demonstration and testing; use established libraries in production.
