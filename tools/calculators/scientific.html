Choose Mode
Toggle between DEG (degree) and RAD (radian) for trigonometric functions.
2
Use Scientific Functions
Click sin, cos, tan, log, ln, sqrt, factorial, and more. Use parentheses for complex expressions.

Memory Functions
Use MC (clear), MR (recall), M+ (add), M- (subtract), MS (store) for memory operations.
